# Advanced-Peripheral-Bus-APB-Verification-Using-UVM-RAL-

## Project Overview

This project focuses on implementing and integrating a UVM
Register Abstraction Layer (RAL) with an existing UVM-based
APB verification environment.

## My Contribution

The base UVM APB environment was provided. My work focused on
the RAL implementation and its integration with the existing
verification components.

### RAL Implementation

- Developed the register model
- Defined register fields and access properties
- Implemented the UVM RAL adapter
- Integrated the register predictor
- Developed RAL-based sequences
- Performed register randomization
- Used frontdoor and backdoor register access
- Debugged mirrored-value and prediction behavior

  ## Tools

- SystemVerilog
- UVM
- UVM RAL
- QuestaSim
- APB
